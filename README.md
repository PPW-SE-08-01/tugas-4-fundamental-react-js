# React JS Practical Guide

## Instruksi Praktikum

Pelajari dan implementasikan seluruh materi React JS yang terdapat dalam modul praktikum secara bertahap.

### Ketentuan Pengerjaan

1. Buat 1 folder yg siap di push ke repository GitHub untuk menyimpan seluruh hasil praktikum.
2. Kerjakan setiap materi sesuai urutan pada modul.
3. Implementasikan setiap contoh kode dan latihan yang diberikan di modul.
4. Pastikan setiap implementasi dapat dijalankan tanpa error.
5. Berikan commit secara berkala menggunakan Git.
